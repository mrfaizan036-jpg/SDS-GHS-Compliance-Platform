# SDS-GHS Compliance Platform

AI-Assisted Regulatory SDS & GHS Labeling Compliance Platform for Chemical Formulators and Exporters.

## Project Status

Phase 2 — System Architecture & Development Setup

## Description

This project aims to assist chemical formulators and exporters in preparing Safety Data Sheets (SDS), GHS hazard labels, and compliance reports using structured chemical data, regulatory rules, and AI-assisted functionality.
